# Urban Echo — DES222 Task 2 Process Journal

**Urban Echo: Layering Digital Experiences onto Physical Places**

This repository contains Joshua Pilcher's DES222 Task 2 process journal, published as a responsive GitHub Pages site.

The journal documents the Urban Echo concept, concept realisations, initial app function and UI, and related existing projects including Snapchat Snap Map and Pokémon GO.

## GitHub Pages

The site is designed to be published from the `main` branch at the repository root.
